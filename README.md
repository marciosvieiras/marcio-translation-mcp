# Marcio Translation MCP

Servidor MCP privado para tradução EN-GB → PT-BR com regras obrigatórias, análise linguística, glossários especializados, corpora paralelos e QA.

## Endpoint

`/mcp`

## Health check

`/health`

## Render

O build recompõe o pacote privado, instala as dependências e reconstrói o banco SQLite antes de iniciar o servidor.
